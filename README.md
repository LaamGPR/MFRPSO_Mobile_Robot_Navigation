# MFRPSO_Mobile_Robot_Navigation
Essa é uma implementação de uma versão melhorada do algoritmo heurístico de ajuste de parâmetros PSO que foi melhorada a partir da reamostragem dos individuos de cada geração. Esse algoritmo foi proposto para solução de um problema de cinemática inversa de manipuladores, mas é facilmente adaptado para o problema de navegação de robôs móveis.
